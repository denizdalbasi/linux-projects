# Number Guessing Game (Bash)

> A simple and fun game for the terminal, written in Bash. Try to find the secret number and check how many tries you need!

---

## What can it do?

* **Easy to play:** Runs directly in your terminal.
* **Smart checks:** If you type letters instead of numbers, it will tell you without crashing.
* **Score count:** It counts your tries and shows your final score when you win.
