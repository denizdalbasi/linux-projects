# Terminal Matrix Chatbot

A simple, interactive command-line chat assistant built entirely in Bash. It uses basic shell features like arrays, case statements, and color codes to give you a fun terminal experience with ASCII art and random replies.

## What It Does

* **Interactive Chat:** Greets you by name and keeps an active conversation going in your terminal.
* **ASCII Art:** Shows cool text graphics when it starts up and says goodbye.
* **Random Answers:** Picks random programming jokes and casual chat lines from lists.
* **Session Stats:** Tracks how many messages you send and shows your system info.
* **No Extra Tools Needed:** Runs on any Linux system using only standard shell commands.

## Commands You Can Use
Type any of these words while chatting:

* help or ? — See the list of commands.

* hello, hi, or hey — Say hello to the bot.

* status or stats — See your message count and system info.

* joke — Get a random programming joke.

* matrix — Show the Matrix art again.

* mood — Check how the bot is feeling.

* exit or quit — Close the chat and leave.
